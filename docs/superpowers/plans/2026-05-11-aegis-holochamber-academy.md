# AEGIS HoloChamber Academy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first governed HoloChamber Academy slice inside EcoVerse: Academy Hub, Evidence Review, WHICHONE Academy framing, route navigation, and verification.

**Architecture:** This is a static EcoVerse/Stitch route implementation. New route source files live under `Stitch-UIs-for-AegisAlign/Agent_Workshop`, are wrapped/generated by `npm run sync:stitch`, and are surfaced through `config/navigation-hierarchy.json`. State remains local/client-side for this slice; no backend persistence or autonomy ranking is introduced.

**Tech Stack:** Vite multipage static site, Stitch HTML route sources, Tailwind CDN in route source pages, vanilla JavaScript, EcoVerse `sync:stitch`, route checker, headless Edge screenshot verification.
